{% comment %} Component UIDialog dùng chung — thay thế alert()/confirm() native bằng dialog HTML. Lý do: dialog native chặn trình duyệt (không automation/AI test được), khó đọc, không hiện được nhiều dòng. Component tự vẽ overlay riêng (không dùng Bootstrap Modal JS) nên hiện được ĐÈ LÊN modal khác mà không lỗi backdrop. Nhúng MỘT lần trong base template ({% include "hub_ui/ui_dialog.html" %}) → mọi trang gọi trực tiếp, KHÔNG include lại. API (đều trả Promise — dùng await trong hàm async): await UIDialog.alert(message, {title?, variant?}) // variant: info|success|warning|danger const ok = await UIDialog.confirm(message, {title?, okText?, cancelText?, variant?}) UIDialog.toast(message, variant?) // thông báo nhỏ góc phải, tự ẩn 3s Message hiện dạng text (tự escape HTML, giữ xuống dòng). Selector ổn định cho automation: #ui-dialog, #ui-dialog-message, #ui-dialog-ok, #ui-dialog-cancel. {% endcomment %}
